# FlowBudget

A lightweight shared expense tracker built because Splitwise keeps putting basic features behind subscriptions and artificial limits.

FlowBudget focuses on what actually matters:

* simple expense tracking
* realtime syncing
* simplified debt settlement
* clean fast UI
* no unnecessary clutter

Built for friend groups, trips, roommates, and everyday shared expenses without the annoyance of paywalls.

## Features

* Shared groups
* Invite codes
* Realtime updates
* Simplified debts
* Free hosting
* Mobile friendly
* Lightweight and fast

## Stack

* Vanilla HTML/CSS/JS
* Supabase
* Netlify

No ads. No settlement limits. No premium nags.

Just split expenses and move on.
